# 마린스키극장에서

인터랙티브 문자메시지 웹사이트입니다.

## 파일
- `index.html` : HTML/CSS/JavaScript가 모두 들어 있는 완성본

## 실행
`index.html`을 브라우저에서 열면 바로 실행됩니다.

## 동작
- 첫 메시지 즉시 표시
- 이후 메시지 3초 간격 표시
- 새 메시지마다 자동 스크롤
- 첫 메시지에 `Моя самая сладкая смерть` 발신자 표시
- 방문자 답장 입력 가능
- 답장은 화면에 추가되지만 실제 전송/저장은 하지 않으며 `메시지를 전송할 수 없습니다.` 표시
- 외부 서버나 데이터베이스 사용 없음

## 공개 배포
GitHub Pages, Netlify, Vercel 등의 정적 호스팅에 `index.html`을 업로드하면 공개 URL로 배포할 수 있습니다.
이 패키지 자체에는 공개 URL이 포함되어 있지 않습니다.
